# MANDALA CHANNEL
## Project Setup & Development Notes

---

## 1. TENTANG PROJECT

Mandala Channel adalah website media yang mengangkat:

- Hindu Jawa
- Hindu Nusantara
- Dharma dan ajaran
- Tokoh Hindu
- Tradisi dan budaya
- Kehidupan spiritual
- Kabar umat
- Ekonomi Hindu
- Jelajah Nusantara
- Podcast
- Video
- Artikel

Website menggunakan struktur frontend HTML, CSS, JavaScript, data lokal, dan nantinya Supabase sebagai backend/CMS.
